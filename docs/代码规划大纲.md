# 3D 病灶 Latent Diffusion 代码规划大纲

> 本文只定义未来代码的职责、接口和数据流，不包含具体实现代码。

## 1. 目标与边界

代码包用于完成以下流程：

```text
NIfTI影像与标签
    ↓
患者级数据划分
    ↓
32³病灶Patch与局部残差数据集
    ↓
AutoencoderKL训练与验证
    ↓
Latent缓存与Scale Factor计算
    ↓
无条件Latent Diffusion训练
    ↓
随机病灶纹理+Mask采样
    ↓
生成样本QC
    ↓
融合回目标脑MR并更新标签
    ↓
生成质量与下游分割评估
```

当前阶段只建立目录结构和规划文档，不编写 Python、YAML、模型或可执行脚本。

### `data/`

负责：

- 扫描 nnUNet 格式的 NIfTI 影像与标签；
- 创建患者级 train／validation／test split；
- 连通域分析和病灶尺寸筛选；
- 裁剪、填充和增强 `32³` patch；
- 构造局部中位数／IQR 标准化残差；
- 生成 patch manifest；
- 使用冻结 VAE 缓存 posterior 参数；
- 计算完整训练集 latent scale factor。

规划文件：

```text

patch_extractor.py
residual_normalization.py
split.py
manifest.py
latent_cache.py
```

### `models/`

负责：

- 根据配置构建 MONAI `AutoencoderKL`；
- 根据配置构建 `DiffusionModelUNet`；
- 构建 DDPM／DDIM scheduler；
- 提供模型参数量和输入输出尺寸检查；
- 统一 checkpoint 中的模型版本标识。

规划文件：

```text
autoencoder.py
diffusion_unet.py
schedulers.py
factory.py
```

### `training/`

负责：

- AutoencoderKL 训练和验证；
- 图像残差损失、mask BCE／Dice 和 KL 损失；
- 可选 perceptual／PatchGAN 消融；
- 无条件 latent diffusion 噪声预测训练；
- AMP、DDP、梯度裁剪、EMA 和 early stopping；
- checkpoint 保存、恢复和 best model 选择；
- 指标日志及训练曲线数据导出。

规划文件：

```text

train_ldm.py

ema.py
checkpoint.py
trainer_state.py
```

### `sampling/`

负责：

- 从高斯噪声开始进行 DDPM／DDIM latent 采样；
- 通过 VAE 解码残差和 mask logits；
- mask 阈值化、连通域筛选、孔洞填充和形态学处理；
- 体积、边界、数值范围和纹理能量 QC；
- 拒绝采样和补采样；
- 保存可复现病灶素材及元数据。

规划文件：

```text

```

### `fusion/`

负责：

- 从目标脑 MR 中采样可插入位置；
- 避免与原病灶及无效图像区域重叠；
- 计算目标位置的局部中位数和 IQR；
- 将生成残差反归一化为目标 MR 强度；
- 根据 mask 距离变换构造软 alpha；
- 融合生成病灶并更新标签；
- 保留原始 affine、spacing、方向和 header；
- 输出新的 nnUNet 数据集与合成元数据。

规划文件：


- 汇总 nnU-Net 下游 Dice、HD95、NSD、病灶召回率和假阳性；

## 4. 规划模型接口

### AutoencoderKL 阶段

逻辑接口：

```text
encode(sample) -> posterior_mu, posterior_sigma
sample_posterior(mu, sigma, seed) -> latent
decode(latent) -> reconstructed_residual, mask_logits
```

### LDM 阶段

逻辑接口：

```text
add_noise(latent, noise, timestep) -> noisy_latent
predict_noise(noisy_latent, timestep) -> noise_prediction
sample(noise, scheduler, seed) -> generated_latent
```

LDM 不接受 mask、位置、图像或类别 condition。

### 融合阶段

逻辑接口：

```text
select_location(target_image, target_mask, seed) -> placement
restore_intensity(residual, local_statistics) -> generated_intensity
build_alpha(mask, width) -> alpha
blend(target_patch, generated_patch, alpha) -> fused_patch
update_label(original_label, generated_mask) -> fused_label
```

## 5. 规划 CLI

统一入口：

```bash
python -m src.synthesize.lesion_ldm.cli.main COMMAND --config CONFIG
```

规划子命令：

```text
prepare-patches  创建患者划分、Patch和Manifest
train-vae        训练AutoencoderKL
evaluate-vae     评估重建质量
cache-latents    缓存posterior并计算scale factor
train-ldm        训练无条件latent diffusion
sample           批量生成病灶素材
evaluate-samples 计算生成质量和多样性
fuse             将病灶融合到目标MR
export-nnunet    导出新的nnUNet数据集
evaluate         汇总完整实验指标
```

每个子命令应支持：

- `--config`：配置路径；
- `--output-dir`：覆盖默认输出根目录；
- `--seed`：覆盖默认随机种子；
- `--resume`：恢复允许恢复的阶段；
- `--dry-run`：只检查输入与计划动作，不写业务输出。

## 8. 测试边界

### 数据测试

- 患者划分互斥；
- patch 尺寸、填充和裁剪坐标正确；
- 图像与 mask 增强同步；
- 局部残差归一化与反归一化近似互逆；
- 无效环形区域和截断病灶能够被拒绝。

### 模型测试

- VAE 输入、latent 和输出尺寸正确；
- mask 输出可计算 BCE 和 Dice；
- latent scale factor 来自完整训练集；
- LDM 前向不接收 condition；
- checkpoint 可以在单卡和 DDP 之间加载。

### 采样测试

- 固定 seed 结果可复现；
- DDPM／DDIM 输出尺寸一致；
- QC 能拒绝空 mask、边界 mask、NaN 和异常体积；
- 最多重试次数受到限制。

### 融合测试

- alpha 之外的体素严格不变；
- 新标签为原标签与生成 mask 的并集；
- affine、spacing、方向和 header 保持一致；
- 输出命名满足 nnUNet 规范；
- 原始数据始终只读。

### 集成测试

使用程序生成的匿名小体积完成：

```text
Patch构建 → VAE单步 → Latent缓存 → LDM单步 → 采样 → 融合 → NIfTI导出
```

测试只验证流程和数据契约，不追求生成质量。

## 9. 实施顺序

1. 配置、公共类型和 manifest；
2. Patch 提取与残差表示；
3. AutoencoderKL 训练和重建评估；
4. Latent 缓存与 scale factor；
5. 无条件 LDM 训练和 EMA；
6. DDIM／DDPM 采样和 QC；
7. 位置采样、反归一化和软融合；
8. nnUNet 数据集导出；
9. 生成质量、消融和下游分割评估；
10. 在 MVP 有收益后增加条件生成和多序列支持。
