# synthesis 代码文档

## placement.py

### placement.compute_mask

输入：三维病例图像数组 `image`。

输出：与输入图像形状一致的布尔型大脑掩膜。

实现方式：

1. 使用单位仿射矩阵将输入数组封装为 nibabel 的 `Nifti1Image`。
2. 使用 `nilearn.masking.compute_brain_mask` 按 `whole-brain` 类型计算完整大脑掩膜。
3. 读取掩膜图像数据并转换为布尔数组后输出。

### placement.transform_donor_mask

输入：供体病灶掩膜 `mask`、随机数生成器 `rng`、最大旋转角度 `rotation_deg`、缩放范围 `scale_range`。

输出：经过随机旋转和等比例缩放的布尔型病灶掩膜。

实现方式：

1. 将掩膜转换为 `float32` 数组，并从三个三维旋转平面中随机选择一个平面。
2. 在指定角度范围内随机取角度，使用零阶插值执行旋转，保持原始数组形状不变。
3. 在 `scale_range` 内随机取等比例缩放系数，使用零阶插值执行缩放。
4. 将缩放结果居中裁剪或居中填充到原始掩膜尺寸。
5. 以 `0.5` 为阈值转为布尔掩膜；若变换后掩膜为空，则抛出异常。

### placement.choose_candidate

输入：病例图像 `image`、病例现有标签 `existing_label`、供体病灶掩膜 `donor_mask`、候选位置中心 `position_centers`、随机数生成器 `rng`、标签保护区膨胀次数 `protected_dilation`、最大尝试次数 `max_attempts`。

输出：有效候选位置的三维体素中心坐标，以及供体掩膜在病例图像中的 ROI 切片。

实现方式：

1. 调用 `compute_mask` 计算病例的大脑掩膜。
2. 对病例中已有标签执行二值膨胀，得到禁止新病灶进入的保护区域。
3. 校验候选位置先验必须为非空的 `N×3` 数组。
4. 每次尝试随机选择一个归一化候选中心，加入标准差为 `0.02` 的高斯扰动，并限制到 `[0, 1]`。
5. 将归一化中心换算为病例图像中的体素坐标，根据供体掩膜尺寸计算 ROI。
6. 若 ROI 超出病例图像边界，则拒绝该候选位置并继续尝试。
7. 检查 `brain[roi][donor_mask]` 是否全部为真，确保整个供体病灶掩膜完整落在病例大脑内。
8. 检查供体病灶是否与已有标签的保护区域相交，若相交则拒绝。
9. 返回首个满足条件的中心和 ROI；达到最大尝试次数仍无有效位置时抛出异常。

### placement.roi_from_mask

输入：完整体积中的病灶掩膜 `mask`、固定补丁尺寸 `patch_shape`、可选边距 `margin`。

输出：以病灶为中心且无需填充的固定尺寸 ROI，以及包含中心、边界框和边距信息的元数据字典。

实现方式：

1. 将病灶掩膜转换为三维布尔数组，校验掩膜非空、补丁尺寸合法且边距可用。
2. 根据所有病灶体素坐标计算病灶边界框及其尺寸。
3. 检查病灶边界框能否放入扣除两侧边距后的补丁空间。
4. 使用病灶边界框中心计算固定尺寸补丁的起止坐标。
5. 检查补丁是否超出完整体积，以及病灶是否满足指定边距。
6. 返回 ROI 切片及中心、起止坐标、边界框和边距元数据。

## sampling.py

### sampling.sample_histogram

输入：训练直方图库 `histograms`、随机数生成器 `rng`、高斯扰动强度 `jitter`。

输出：随机采样并归一化后的 `float32` 直方图概率分布。

实现方式：

1. 校验训练直方图库非空，并随机选择一个直方图副本。
2. 当 `jitter` 大于零时，为每个直方图区间加入对应标准差的高斯扰动。
3. 将负值裁剪为零，校验扰动后分布总量大于零。
4. 使用总和归一化直方图，使各区间概率之和为一。

### sampling.sample_composite_patch

输入：生成模型 `model`、背景补丁 `background`、病灶掩膜 `mask`、条件直方图 `histogram`、推理设备 `device`、随机种子 `seed`、亮度边距 `brightness_margin`、亮度过渡距离 `brightness_transition_voxels`。

输出：模型生成并调亮后的病灶补丁，以及与原始背景硬合成后的完整补丁。

实现方式：

1. 将背景、掩膜和直方图转换为规定数据类型，校验背景与掩膜形状一致且掩膜非空。
2. 为三个输入增加批次和通道维度，转换为 PyTorch 张量并移动至推理设备。
3. 创建指定设备上的随机数生成器并设置种子，保证采样可复现。
4. 调用模型的 `sample_patch` 方法生成病灶图像，并将结果转回 NumPy 数组。
5. 调用 `brighten_lesion_interior` 渐进提高病灶内部亮度。
6. 调用 `hard_composite` 仅替换掩膜内部体素，同时返回生成补丁和合成补丁。

### sampling.brighten_lesion_interior

输入：背景补丁 `background`、模型生成补丁 `generated`、病灶掩膜 `mask`、目标亮度边距 `margin`、过渡距离 `transition_voxels`。

输出：病灶内部经过渐进亮度调整的生成补丁。

实现方式：

1. 转换输入数据类型，校验三者形状一致、掩膜非空、亮度参数有效。
2. 按过渡距离膨胀病灶掩膜，提取病灶外部邻接环带。
3. 以环带背景强度的第 90 百分位数作为背景参考，以病灶生成强度的第 25 百分位数作为病灶参考。
4. 计算使病灶参考强度达到“背景参考强度加亮度边距”所需的非负偏移量。
5. 使用病灶内部距离变换生成从边界到中心逐渐增大的权重。
6. 按权重增加病灶内部强度，并将结果限制在 `[-1, 1]`。

### sampling.hard_composite

输入：背景补丁 `background`、生成补丁 `generated`、病灶掩膜 `mask`。

输出：仅在掩膜内部使用生成值的合成补丁。

实现方式：

1. 将输入转换为 NumPy 数组并校验形状完全一致。
2. 复制背景补丁，避免修改输入数组。
3. 仅使用生成补丁中掩膜为真的体素替换对应背景体素，确保掩膜外背景保持完全不变。

## quality.py

### quality.qc_patch

输入：背景补丁 `background`、模型生成补丁 `generated`、合成补丁 `composite`、病灶掩膜 `mask`、质量控制配置 `config`。

输出：包含是否通过、失败原因、掩膜体素数、背景是否保持不变及边界强度跳变值的质量控制字典。

实现方式：

1. 检查病灶掩膜体素数是否至少为 8，以及掩膜是否接触补丁任一边缘。
2. 精确比较掩膜外的合成结果与原始背景，检查背景是否被改动。
3. 检查合成补丁是否全部为有限数值。
4. 检查掩膜内部生成值的最大绝对强度是否超过配置阈值。
5. 使用一次腐蚀等效操作得到病灶内边界，并使用一次膨胀得到病灶外边界。
6. 计算内外边界平均强度差，检查是否超过允许的最大边界跳变。
7. 汇总所有失败原因并生成质量控制结果。

### quality.aggregate_case_qc

输入：病例中所有已接受病灶的记录 `lesions`、病例非病灶背景是否精确保持不变 `background_exact`。

输出：病例级质量控制汇总字典。

实现方式：

1. 收集每个病灶的边界跳变值和失败原因。
2. 仅当病例至少包含一个病灶且所有病灶均通过质量控制时，将病例标记为通过。
3. 对失败原因去重并排序，计算所有病灶的平均边界跳变。
4. 记录背景一致性和已接受病灶数量。

## runtime.py

### runtime.load_inference_runtime

输入：项目配置字典 `config`。

输出：加载后的生成模型、检查点信息、推理设备和训练直方图库。

实现方式：

1. 从预处理数据目录定位 `train_histograms.npy`，若文件不存在则抛出异常。
2. 加载训练直方图库并创建独立副本。
3. 检测 CUDA 是否可用，自动选择 GPU 或 CPU 推理设备。
4. 使用配置中的检查点路径和模型配置调用 `load_model_checkpoint`。
5. 返回模型、检查点、设备和直方图库供合成流水线使用。

## pipeline.py

### pipeline._attempt_seed

输入：基础随机种子 `base_seed`、病例索引 `case_index`、病灶索引 `lesion_index`、尝试索引 `attempt`。

输出：当前生成尝试使用的确定性整数随机种子。

实现方式：

1. 使用不同数量级的固定系数分别组合病例索引和病灶索引。
2. 加入基础种子与尝试索引，使每次尝试具有稳定且可复现的种子。

### pipeline._select_donor

输入：供体记录列表 `entries`、目标病例编号 `target_case`、随机数生成器 `rng`。

输出：随机选中的一条供体病灶记录。

实现方式：

1. 优先排除与目标病例编号相同的供体记录，避免从目标病例自身选择病灶。
2. 若排除后没有候选记录，则回退到完整供体列表。
3. 使用随机数生成器均匀随机选择一条记录。

### pipeline.synthesize

输入：包含数据、模型、归一化和合成参数的项目配置字典 `config`。

输出：包含病例和病灶生成统计、失败病例、完成率、质量控制通过率及输出目录的合成摘要字典。

实现方式：

1. 读取配置并创建图像、标签、掩膜和元数据输出目录，校验每例病灶数量和最大生成尝试次数。
2. 加载数据清单、数据划分和位置先验，筛选训练集供体病灶并确定目标病例列表。
3. 调用 `load_inference_runtime` 加载模型、检查点、推理设备和训练直方图库。
4. 对每个目标病例加载并转为 RAS 方向的原始图像和标签，检查二者形状一致，并创建累计图像、标签和插入掩膜。
5. 对每个待生成病灶执行多次尝试：生成确定性随机种子、选择供体、加载并变换供体掩膜、归一化当前病例图像、选择合法放置位置、采样直方图、生成合成补丁并执行补丁质量控制。
6. 对运行异常或未通过质量控制的尝试进行计数并继续尝试，直至接受一个病灶或达到最大尝试次数。
7. 对通过质量控制的病灶执行反归一化，仅替换病灶掩膜内部图像体素，并累计更新标签、插入掩膜和病灶元数据。
8. 若病例没有任何成功病灶，则记录为失败病例并跳过输出；否则将图像、标签和掩膜恢复为源图像方向。
9. 保存合成 NIfTI 图像、标签和插入掩膜，检查非病灶背景是否精确保持不变。
10. 汇总病例级质量控制、检查点、数据哈希、输出路径等元数据，计算元数据哈希并写入 JSON 文件。
11. 汇总所有病例的完成数量、接受病灶数量、拒绝尝试数量、完成率和质量控制通过率，写入 `summary.json` 后返回。
